# Agent Input Rejection Example

This example demonstrates how an "agent" system explicitly rejects invalid inputs to maintain reliability and integrity. It simulates an agent that processes commands, validating incoming requests against predefined rules and clearly distinguishing between valid inputs that are processed and invalid ones that trigger specific rejections. The code includes a "rejection corpus" to test the agent's robustness in handling various invalid scenarios.

## Language

`python`

## How to Run

Save the code as `agent_validator.py`. Run from your terminal using `python agent_validator.py`.
